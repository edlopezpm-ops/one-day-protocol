# SOP 02 — Open it in Obsidian

Optional. The app runs on its own; this is for people who'd rather have notes.

**You need:** [Obsidian](https://obsidian.md) (free). No plugins, no account, no sync.

---

## Steps

1. Download `Obsidian-Vault.zip` from the [latest release](https://github.com/edlopezpm-ops/one-day-protocol/releases/latest) and unzip it.
2. In Obsidian, click **Open folder as vault**.
   - First launch: it's on the welcome screen.
   - Already using Obsidian: vault name in the bottom-left corner → **Manage vaults** → **Open folder as vault**.
3. Select the **`vault`** folder itself, not the folder above it.
4. Obsidian asks whether you trust the author — yes. These are plain Markdown files, no code.
5. Open **`00 START HERE.md`**.

## What's in there

| File | What you get |
| --- | --- |
| `00 START HERE.md` | The index. Every branch links from here. |
| `One-Day Protocol.canvas` | The mind map, inside Obsidian. Drag, zoom, edit. |
| `Workbook.md` | Every question with a blank quote block under it, plus the guidance for each. |

Press `Ctrl+G` (`Cmd+G`) for graph view — the notes are wiki-linked, so the graph draws the model's structure.

Already answered in the browser? Export from there and drag the `.md` into this vault.

## Keeping it out of your daily vault

If you already use Obsidian, either open this as its own vault (above), or copy the `vault` folder into your existing one as a subfolder. The second puts these notes in your existing graph.

---

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| No "Open folder as vault" | Vault name, bottom-left → **Manage vaults**. |
| Canvas won't open | Update Obsidian — Canvas is built in since v1.1. |
| Links show as literal `[[text]]` | You opened the folder in a text editor, not Obsidian. |
| Vault looks empty | You picked the folder above `vault`. Re-open and choose `vault`. |
