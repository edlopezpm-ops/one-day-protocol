# SOP 02 — Open it in Obsidian

**Time:** 2 minutes. **You need:** [Obsidian](https://obsidian.md) (free). Nothing else — no plugins, no account, no sync.

---

## Steps

1. **Get the files.** Download and unzip `one-day-protocol.zip` from the [latest release](https://github.com/edlopezpm-ops/one-day-protocol/releases/latest).
2. **Open Obsidian.**
3. Click **Open folder as vault**.
   - First launch: it's on the welcome screen.
   - Already using Obsidian: click the vault name in the bottom-left corner → **Manage vaults** → **Open folder as vault**.
4. Navigate into the unzipped folder and select the **`vault`** folder. Pick `vault` itself, not the folder above it.
5. Obsidian asks to trust the author — say yes. There is no code in these files, only Markdown.
6. Open **`00 START HERE.md`**.

Done.

---

## What to open

| File | What you get |
| --- | --- |
| `00 START HERE.md` | The index. Every branch links from here. |
| `One-Day Protocol.canvas` | **The mind map, inside Obsidian.** Drag it around, zoom, edit nodes. |
| `Workbook.md` | Every question with a blank quote block under it. Type your answers straight in. |

**Graph view:** press `Ctrl+G` (`Cmd+G` on Mac). The notes are wiki-linked, so the graph draws the structure of the model.

---

## Writing your answers

Open `Workbook.md` and type under each `>` line. The checkboxes in the branch notes (`- [ ]`) tick when you click them.

If you already answered in the browser version, press **Export Markdown** there and drag the downloaded file into this vault. Both live side by side.

---

## Keeping the vault separate from your own notes

If you already have a vault you use daily, don't merge these files into it. Either:

- open this as its own vault (steps above), **or**
- copy the `vault` folder into your existing vault as a subfolder named `One-Day Protocol`.

Both work. The second one puts these notes in your existing graph.

---

## If something looks wrong

| Symptom | Fix |
| --- | --- |
| "Open folder as vault" is missing | Click the vault name, bottom-left → **Manage vaults**. |
| The canvas file won't open | You're on a very old Obsidian. Update it — Canvas has been built in since v1.1. |
| Links show as plain text `[[like this]]` | You opened the folder in a text editor, not Obsidian. |
| The vault looks empty | You selected the folder *above* `vault`. Re-open and pick `vault` itself. |
